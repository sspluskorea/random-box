1. 서비스 이용 순서

모두의박스는 포인트를 충전하고 랜덤박스를 구매한 뒤, 당첨 상품을 배송받거나 캐시로 전환하는 서비스입니다. 충전 실적에 따른 천장 보상과 누적 혜택은 마이페이지에서 함께 확인합니다.

처음 이용할 때

  1. 회원가입에서 회원정보와 동의 항목을 확인합니다. 로그인 후 마이페이지에서 포인트와 보관 상품을 확인합니다.
  2. 포인트 충전에서 금액과 보너스를 확인하고 승인을 진행합니다. 충전금과 보너스는 따로 표시됩니다.
  3. 랜덤박스에서 구성 상품과 확률을 확인합니다. 박스 열기를 누르면 수량과 결제수단을 선택할 수 있습니다. 연락처를 다시 입력할 필요는 없습니다.
  4. 구매가 완료되면 박스가 열리고 결과가 표시됩니다. 애니메이션을 건너뛰어도 이미 결정된 결과와 결제금액은 바뀌지 않습니다.
  5. 보관함에서 상품을 선택해 배송을 신청하거나, 표시된 금액을 확인하고 캐시로 전환합니다.

화면을 확인하는 방법

사용자와 관리자 화면을 같은 브라우저에서 열면 설정과 거래 기록이 서로 반영됩니다. 가입·로그인·결제 입력란은 비워 두고도 흐름을 확인할 수 있습니다. 실제 본인인증, 카드 승인, 배송 접수는 연결되지 않았으므로 실제 개인정보나 카드정보는 입력하지 않습니다.

다른 기기나 브라우저에는 별도의 기록이 보입니다. 현재 화면은 서비스 흐름을 검토하는 제작본이며, 공개된 관리자 주소에도 실제 운영 권한 인증이 적용되어 있지 않습니다.

2. 나의 쇼핑과 이용 기록

메뉴사용 방법과 확인할 내용
랜덤박스와 검색박스 이름·카테고리로 찾습니다. 박스 열기는 구매 화면, 담기는 장바구니, 하트는 관심 박스로 연결됩니다.
구성과 확률상품 이미지·등급·재고·최종 확률을 확인합니다. 상품명을 누르면 브랜드, 사양, 구성, 기준가격, 설명과 상세 이미지가 나옵니다.
장바구니와 관심 박스담은 박스를 확인하고 구매할 박스를 선택합니다. 구매 화면에서 수량·잔액·최종 결제금액을 다시 확인합니다.
마이페이지포인트·캐시·보관 상품·배송 진행과 천장 보상을 한 번에 확인합니다. 세부 내역은 왼쪽 메뉴로 이동합니다.
보관함배송을 기다리는 상품과 기한을 확인합니다. 배송 신청, 캐시 전환, 미수령 환급 중 가능한 처리를 선택합니다.
주문·배송신청 상품, 주소, 배송비와 상태를 확인합니다. 관리자가 등록한 택배사와 송장번호가 표시됩니다.
나의 언박싱본인의 박스 구매와 당첨 기록을 확인합니다. 공개 언박싱과 구분되어 있습니다.
언박싱과 당첨 랭킹공개 선택이 켜진 개봉 기록을 확인합니다. 현재 브라우저 기록과 예시 표시는 실제 전체 회원의 검증 자료를 뜻하지 않습니다.
거래 명세본인의 충전·구매 등 거래 내용을 확인합니다. 실제 세금계산서나 PG 영수증 발급 기능과는 별도입니다.
이용방법과 확률 안내충전부터 수령까지의 순서, 추첨 방식과 확률 해석을 확인합니다.

평균 당첨 간격은 장기간 반복했을 때의 평균입니다. 1%는 평균 100회당 1회라는 뜻이며, 100회 안에 반드시 당첨된다는 뜻은 아닙니다. 100회 중 한 번 이상 당첨될 확률은 약 63.4%입니다.

3. 포인트와 캐시 및 취소

잔액은 세 가지로 구분합니다

잔액용도
충전 포인트승인된 충전 원금입니다. 천장과 누적 이벤트의 인정 결제금액에 포함됩니다.
보너스 포인트충전 보너스·출석·이벤트·자동 전환으로 받습니다. 천장 인정금액에는 포함되지 않습니다.
캐시상품 전환이나 이벤트로 받는 사이트 내 구매용 잔액입니다. 계좌 출금 기능은 없습니다.

충전 내역과 취소

포인트 내역에서 충전금, 보너스, 사용 기록을 확인합니다. 미사용 충전은 취소 버튼으로 남은 원금과 회수 보너스를 확인한 뒤 처리합니다. 관리자는 금액을 입력해 부분 취소할 수도 있습니다. 원금이나 회수할 보너스가 부족하면 즉시 취소되지 않으며 고객센터 검토가 필요합니다.

상품을 배송받지 않을 때

캐시 전환은 상품 기준가격의 기본 60%를 받는 방식입니다. 상품별 고정 전환액이 있으면 그 금액이 우선합니다. 당첨 당시의 조건을 보존하므로 이후 관리자가 전환율을 바꿔도 이미 받은 상품의 금액은 달라지지 않습니다.

상품 미수령 환급은 구매금액을 기준으로 수수료를 계산하는 별도 절차입니다. 상품 가치가 높아도 환급 기준이 커지지 않습니다. 캐시로 구매한 상품은 캐시로, 포인트 구매분은 사용한 잔액 종류에 맞춰 반환합니다. 관리자 승인 방식이면 승인 전에는 잔액이 늘어나지 않습니다.

새 일반 당첨 상품은 기본 10일 이내 수령을 신청해야 합니다. 기한이 지나면 당시 전환액을 보너스 포인트로 지급합니다. 3일 전과 1일 전 구간에 화면을 열면 알림함에 안내합니다. 문자·이메일은 발송하지 않습니다. 천장 확정보상과 배송 신청 상품은 제외하며, 기한이 없던 과거 상품에는 소급 적용하지 않습니다.

취소·반품 신청은 상품 하자나 배송 문제 등을 접수하는 창구입니다. 상품 미수령 환급 수수료가 모든 반품에 일괄 적용되는 것은 아닙니다. 접수 후 고객센터 답변을 확인합니다.

4. 천장 보상과 참여 혜택

A와 B는 각각 쌓입니다

기본 기준은 B등급 1,000만원, A등급 4,000만원입니다. 승인된 충전 원금에서 취소한 금액을 차감합니다. 같은 포인트로 박스를 구매하거나 캐시를 다시 사용해도 적립금액은 늘지 않습니다. 일반 추첨으로 A~E 상품을 받아도 게이지는 초기화되지 않습니다.

천장 화면에서 남성 명품·여성 명품·가전제품 중 카테고리를 선택하고 지급 예정 상품을 확인합니다. 확정보상을 수령하면 상품이 보관함에 들어오고 해당 등급의 천장 게이지 전체가 0으로 초기화됩니다. 초과금액은 이월하지 않습니다. 재고가 없으면 지급하지 않고 받을 권리를 유지합니다.

예시처리 결과
4,000만원 충전A 4,000만원, B 4,000만원으로 각각 계산합니다.
B 보상 1회 수령B는 0원으로 초기화되고 A는 4,000만원을 유지합니다.
이후 A 보상 수령A와 B 모두 0원입니다.
보상 후 100만원 충전 취소A와 B에 각각 정산 필요액 100만원이 반영됩니다. 받은 상품을 자동 회수하지는 않습니다.

누적 결제 혜택

기본 구간은 100만·200만·300만·500만·1,000만원입니다. 충전 조건을 충족하면 설정된 포인트, 캐시, 특별 박스 이용권, 버닝 이용권 또는 상품을 지급합니다. 반복 이벤트는 다음 회차에 추가 기준금액을 채워야 합니다. 재고 등으로 지급되지 못한 혜택은 조건을 확인한 뒤 다시 받을 수 있습니다.

버닝은 지정 박스의 A등급 합산 확률을 기본 10%로 조정하는 이용권입니다. 나머지 등급은 비율에 맞게 조정됩니다. 구매 전에 최종 확률과 남은 사용 횟수를 확인합니다.

가입 축하 보상은 최초 1회, 출석은 한국 시간 기준 하루 1회 지급합니다. 친구 초대는 추천 코드를 등록하고 신규 회원의 유효 충전 조건을 충족하면 양쪽에 지급합니다. 기본 보상은 가입 1,000P, 출석 100P, 추천 양쪽 각 1,000P이며 최소 충전 조건은 1만원입니다.

5. 사용자 계정과 소식 확인

마이페이지에서 보관함, 주문·배송, 환급 내역, 포인트·캐시, 천장 보상과 참여 혜택으로 이동합니다. 관심 박스는 하트 버튼으로 등록하고 장바구니에서는 구매할 박스를 고릅니다. 알림함은 보상 지급과 수령 마감 안내를 확인하는 곳입니다.

혜택과 참여 기록

출석체크는 한국 시간 기준 하루 한 번 보너스를 지급합니다. 친구 초대는 추천 코드를 전달하거나 등록한 뒤 충전 조건을 충족해야 지급됩니다. 내 쿠폰에서는 기간과 사용 가능 상태를 확인하고 결제 화면에서 적용합니다. 특별 박스 이용권은 누적 혜택 화면에서 열고, 버닝 이용권은 지정 박스 결제 화면에서 선택합니다.

공지와 고객센터

공지사항과 이벤트에서 공개 안내를 읽습니다. 이벤트 참여 버튼은 참여 기록을 남기는 기능이며, 모든 보상을 자동 지급하는 버튼은 아닙니다. 고객센터의 자주 묻는 질문을 확인한 뒤 1:1 문의를 등록하면 내 문의에서 답변을 볼 수 있습니다. 문자나 이메일은 자동 발송되지 않습니다.

내 정보와 권리 요청

회원정보 수정에서 기본 정보와 당첨 내역 공개 여부를 관리합니다. 계정 복구, 회원 탈퇴, 개인정보 권리 요청, 취소·반품 신청은 고객센터에 접수하는 화면입니다. 접수만으로 실제 인증, 비밀번호 변경, 데이터 삭제나 상품 회수가 실행되지 않습니다. 거래 명세는 본인의 기록이며 세금계산서나 PG 영수증 발급과 다릅니다.

언박싱·당첨 랭킹에서는 공개를 허용한 개봉 기록을 확인합니다. 커뮤니티는 글 등록과 열람, 선물함은 등록된 선물 기록 조회를 제공합니다. 포인트샵과 상품 교환 게시판은 선택 기능으로 기본 주요 메뉴에서 제외했으며 해시패스는 제공하지 않습니다.

6. 관리자 화면을 처음 사용할 때

이후 장은 관리자 업무 안내입니다. 먼저 같은 브라우저에 사용자 화면과 관리자 화면을 각각 열어 두세요. 설정 저장 후 사용자 화면에서 결과를 확인할 수 있습니다. 다른 기기나 브라우저의 기록은 자동으로 합쳐지지 않습니다.

목록에서 필요한 기록 찾기

  1. 왼쪽 메뉴 검색으로 업무를 찾습니다. 각 화면의 설명을 읽고 목록 검색에 이름이나 ID를 입력합니다. 상태 필터를 함께 사용하면 확인할 범위가 줄어듭니다.
  2. 목록은 이름·금액·상태 등 핵심 정보만 표시합니다. 상세보기를 누르면 해당 행 아래에 나머지 정보가 펼쳐집니다. 수정 버튼은 내용을 바꾸는 창이고 상세보기는 확인하는 기능입니다.
  3. 상품 목록에는 모든 등급 필터가 있습니다. A~E 중 하나를 고른 뒤 상태를 함께 확인합니다. 결과가 없으면 검색어와 필터를 먼저 해제합니다.
  4. 표의 오른쪽이 보이지 않으면 표 안에서 가로로 스크롤합니다. 수정창이 길면 창 안을 아래로 내려 저장 버튼을 찾습니다. 필수 항목, 원·P·캐시·개·% 단위를 확인하고 저장합니다.

저장한 뒤 확인할 것

완료 안내가 나왔는지 확인한 뒤 목록의 값과 사용자 화면을 봅니다. 오류가 나오면 해당 입력값을 고치고 다시 저장합니다. CSV 내보내기는 현재 조회 목록을 확인하는 용도이며 전체 데이터 복구용 백업은 아닙니다.

상품 판매 준비 순서 바로가기에서는 1 상품 등록·재고 → 2 랜덤박스 구성 → 3 당첨 확률 확인 → 사용자 판매 화면 확인으로 이동합니다. 이 순서대로 준비하면 누락을 줄일 수 있습니다.

7. 상품을 등록하고 재고 확인하기

사용 메뉴는 상품 등록·재고입니다. 상품명, 등급, 기준가격, 매입원가, 재고, 브랜드·사양·설명과 이미지 파일을 준비합니다. 기준가격은 당첨 상품의 가치이고 박스 판매가격과 다릅니다.

  1. 새로 등록을 누르고 이름과 A~E 등급, 가격·재고·판매 상태를 입력합니다. 대표 이미지와 상세 이미지는 파일 업로드로 등록합니다. 입력한 단위와 저장 오류를 확인합니다.
  2. 천장 전용 상품은 천장 보상 전용 설정과 남성 명품·여성 명품·가전제품 종류를 지정합니다. 일반 박스에 넣을 상품과 구분합니다. 상품별 캐시 전환액을 정하면 기본 전환율보다 우선 적용됩니다.
  3. 저장 후 상품 목록과 상세보기를 열어 값을 확인합니다. 해당 상품이 포함된 박스의 사용자 상세 화면에서 사진과 확률을 보고 상품명을 눌러 브랜드·사양·설명을 확인합니다.

당첨내역과 판매내역

상품 행의 당첨내역은 해당 상품 ID의 개봉 기록만 보여줍니다. 판매내역은 연결된 구매·이벤트 개봉·배송 주문을 조회합니다. 선택 상품 표시와 상품 필터 해제를 확인하세요. 다른 메뉴로 이동하면 연결 필터는 해제됩니다. 이름이 같은 상품도 ID로 구분합니다.

등록이나 삭제가 되지 않을 때

필수 이름과 숫자 범위를 먼저 확인합니다. 재고가 없거나 판매 상태가 중지면 구매 또는 보상 지급이 제한됩니다. 박스에서 참조하는 상품은 확률이 0%여도 먼저 구성에서 제외해야 삭제할 수 있습니다. 이미 발생한 당첨·거래 기록을 삭제해 해결하지 않습니다.

8. 박스를 구성하고 확률을 공개하기

사용 메뉴는 랜덤박스 관리와 상품별 당첨 확률입니다. 상품 등록을 마친 뒤 박스 이름, 판매가격, 수량, 카테고리, 판매 상태와 이미지를 준비합니다.

  1. 랜덤박스 관리에서 새로 등록 또는 수정을 선택합니다. 대표 이미지와 사용자 상세페이지 이미지는 수정창에서 업로드합니다. 목록에는 이미지 편집 항목을 펼쳐 놓지 않습니다.
  2. 상품별 당첨 확률에서 구성 상품을 선택하고 각각의 최종 확률을 입력합니다. 합계가 100%인지, 재고가 있는지, 중복 상품이 없는지 확인합니다. 등급별 합계와 예상 원가도 함께 살펴봅니다.
  3. 저장 후 사용자 판매 화면으로 이동해 박스 가격·수량·이미지를 확인합니다. 구성과 확률 보기에서 개별 상품 이미지와 최종 확률이 관리자 설정과 같은지 확인합니다.

확률을 이해하는 방법

1%는 평균적으로 100회당 1회라는 뜻이며 100번 안에 반드시 당첨되는 것은 아닙니다. 누적 가능성 계산도 같은 확률의 독립 추첨을 가정합니다. 확정 지급은 천장 보상 조건과 별도입니다.

기본 6개 박스는 기존 금액대 방식이며 상품별 확률로 변경할 수 있습니다. 신규 리워드 시그니처 박스는 개별 상품 확률입니다. 금액대 방식에서는 해당 구간에 재고 상품이 있어야 합니다. 합계 오류·구성 중복·품절 안내가 나오면 구성을 수정한 후 다시 저장합니다. 상품 재고와 박스 잔여 수량은 각각 확인해야 합니다.

9. 충전과 배송 및 환급 기준 정하기

충전 금액·보너스

선택 가능한 충전 금액과 보너스율을 입력해 저장합니다. 사용자 포인트 충전에서 금액 버튼과 적립 예정액을 확인합니다. 3만원 충전에 5%라면 유료 30,000P와 보너스 1,500P가 구분되어야 합니다. 천장에는 실제 결제 원금만 반영됩니다.

배송비·배송 정책

기본 배송비, 무료배송 기준과 안내 문구를 저장합니다. 보관함에서 상품을 선택해 배송 신청 화면의 비용을 확인합니다. 상품가격과 배송비를 혼동하지 말고, 주소·택배 접수는 실제 배송 업체와 별도로 처리해야 합니다.

환불·수수료 정책

상품 미수령 환급 수수료와 승인 방식을 설정합니다. 사용자 보관함에서 미수령 환급을 열어 구매 기준가·수수료·반환 잔액을 확인합니다. 승인 방식이면 관리자 처리 전에는 잔액이 늘어나지 않습니다. 상품 하자나 법정 반품 기준을 이 수수료와 동일하게 안내하지 않습니다.

상품 전환·복원 정책

기본 캐시 전환율과 미수령 자동 전환 시간을 입력합니다. 기본은 상품가의 60%, 240시간입니다. 현재 기한 확인 및 처리는 실행 시점의 알림과 만료 대상을 확인합니다. 수동 전환은 캐시, 만료 전환은 보너스 포인트입니다. 이미 당첨된 상품은 당시 전환액과 기한을 보존합니다.

설정 저장이 거절되면 음수·허용 범위·필수값과 화면 오류를 확인합니다. 값이 저장돼도 과거 상품 금액이 바뀌지 않는 것은 당시 조건을 보존하기 때문입니다. 과거 포인트 전환 복원 기능은 기존 기록용이며 새 캐시 전환을 임의로 되돌리는 기능으로 사용하지 않습니다.

10. 충전 취소와 상품 환급 처리하기

충전 취소는 결제한 충전 원금을 취소하는 작업입니다. 상품 미수령 환급은 박스 구매가에서 수수료를 빼는 작업이고, 상품 캐시 전환은 상품 가치에 따른 전환액을 받는 작업입니다. 같은 환급으로 취급하지 않습니다.

충전 내역에서 취소하기

  1. 회원과 충전 기록을 찾고 상세보기에서 원금·보너스·이미 취소한 금액을 확인합니다.
  2. 취소할 금액을 남은 원금 이내로 입력합니다. 원금과 비례 보너스가 회수되며 천장 인정금액도 다시 계산됩니다.
  3. 저장 후 충전 상태와 누적 취소액, 해당 회원 지갑을 확인합니다. 부분 취소 후 남은 금액도 취소할 수 있지만 이미 사용한 원금이나 보너스가 부족하면 거절됩니다.

상품 미수령 환불 승인하기

승인 대기 요청을 찾아 구매 기준가·수수료·환급액·지급 방식을 확인한 뒤 승인 또는 반려합니다. 캐시 구매는 캐시로, 포인트 구매는 유료·보너스 사용 비율에 맞춰 반환합니다. 원결제 내역이 있는 카드 구매의 원결제 환불은 별도로 표시됩니다. 반려하면 보관 상태로 돌아갑니다.

포인트 원장으로 결과 확인하기

포인트 원장에서 회원·금액·잔액 종류·처리 사유를 조회하고 상세보기로 연결 거래번호를 확인합니다. 원장은 조회 기록이며 이 화면에서 잔액을 직접 수정하지 않습니다. 승인 후 잔액이 예상과 다르면 본인 기록인지, 캐시와 포인트를 혼동했는지, 동일 요청이 이미 처리됐는지 먼저 확인합니다.

11. 당첨 상품과 배송 주문 확인하기

개봉·당첨 이력

회원이나 상품으로 검색하고 상세보기에서 거래번호와 당시 확률표를 확인합니다. 상품 목록의 당첨내역에서 왔다면 선택 상품 필터가 적용되어 있습니다. 현재 확률을 수정해도 과거 구매 확률은 바뀌지 않습니다. 이력은 조회용이며 당첨 결과를 임의로 등록하거나 변경하지 않습니다.

회원 보관함

회원과 상품을 찾고 보관·배송·환급 상태를 확인합니다. 상세보기에서 구매가, 사용한 잔액, 전환액, 수령 마감과 연결 주문을 확인합니다. 실제 처리는 주문·배송 관리 또는 상품 미수령 환불에서 진행합니다. 이미 처리된 상품을 중복으로 환급하거나 배송하지 않습니다.

주문·배송 관리

  1. 주문 구분을 먼저 봅니다. 구매는 박스 구매금액, 이벤트 개봉은 이용권 처리, 배송 주문은 배송비를 표시하므로 모두 상품 판매액으로 합산하지 않습니다.
  2. 배송 요청을 수정해 받는 분과 주소, 택배사, 송장번호, 배송 상태를 입력하고 저장합니다. 실제 택배 접수는 외부 배송 업무로 별도 진행합니다.
  3. 사용자 주문·배송과 보관함에서 상태·송장번호를 확인합니다. 상품 판매내역에서 연결된 주문만 보고 있다면 상품 필터 해제로 전체 내역을 확인할 수 있습니다.

기록이 보이지 않으면 검색·상태·상품 연결 필터를 해제합니다. 잘못된 회원이나 주문이 아닌지 ID를 확인한 뒤 수정하고, 배송 접수 여부는 화면 상태만으로 단정하지 않습니다.

12. 회원 정보와 잔액 관리하기

회원 관리

이름·이메일·연락처로 회원을 찾고 상세보기에서 정보를 확인합니다. 수정을 열어 기본 정보와 상태를 저장합니다. 사용자 내 정보에서 반영을 확인하세요. 실제 본인인증이나 회원 계정의 보안 차단을 구현한 화면은 아닙니다.

회원별 포인트·캐시

  1. 처리할 회원과 잔액 종류를 먼저 확인합니다. 포인트 지급·차감과 회원 캐시 지급·차감은 별도 작업입니다.
  2. 지급은 양수, 차감은 음수 금액으로 입력하고 처리 사유를 남깁니다. 실제 충전 결제를 취소하려는 경우에는 이 메뉴 대신 충전 내역을 사용합니다.
  3. 저장 후 해당 회원의 지갑과 포인트 원장 또는 캐시 내역을 확인합니다. 다른 회원 잔액이 바뀌지 않았는지도 확인합니다.

잔액 부족이나 사유 누락 오류가 나오면 금액과 회원을 다시 확인합니다. 임의로 유료 충전금을 만들어 취소를 우회하지 않습니다. 수동 지급한 포인트·캐시는 천장 결제금액에 포함되지 않으며, 천장 게이지 정정은 천장 보상 메뉴에서 따로 처리합니다.

13. 천장 보상 설정과 확정보상 지급

천장 보상은 실제 충전 결제금액으로 계산합니다. 기본 B등급은 1,000만원, A등급은 4,000만원입니다. 확정보상 1개를 보관함에 지급하면 해당 등급의 게이지 전체를 0으로 초기화합니다. 초과금액도 이월하지 않습니다. 다른 등급과 일반 추첨 결과는 별도로 유지됩니다.

보상 기준 설정 탭

A·B 목표 금액을 입력해 저장합니다. 상품 등록·재고에서 천장 보상 전용 상품의 등급·종류·재고를 준비합니다. 진행 중인 회차는 기존 기준을 유지하고 다음 회차부터 새 기준을 적용합니다. 이번 기준과 다음 기준이 다르면 화면에서 함께 확인합니다.

회원별 진행 현황 탭

  1. 회원 이름이나 번호로 검색하고 상태 필터를 선택합니다. 처리할 회원을 선택한 뒤 해당 등급의 게이지와 남은 금액을 확인합니다.
  2. 상품 지급에서는 등급·받을 상품 종류·지급 예정 상품을 확인하고 처리 사유를 입력합니다. 확정보상 지급 · 해당 게이지 초기화를 누르면 상품 1개가 보관함에 지급됩니다.
  3. 금액 정정에서는 등급, 더하거나 뺄 금액과 사유를 입력하고 천장 게이지 정정 저장을 누릅니다. 보상 자격용 금액만 바뀌며 실제 충전 기록과 포인트·캐시는 바뀌지 않습니다.

지급 내역과 환불 후 보상 확인 탭

지급 내역에서 수령 상품·등급·처리 사유와 게이지 초기화 기록을 확인합니다. 환불 후 보상 확인에서는 보상을 받은 뒤 취소한 내역에 검토 메모를 남깁니다. 메모 저장은 금액이나 상품을 회수하지 않습니다.

기준 미달이면 지급할 수 없습니다. 품절이면 상품 재고를 보충하거나 다른 종류를 선택하며 수령 권리는 유지됩니다. 사용자 천장 화면과 보관함에서 결과를 확인하세요. 4,000만원에서 B를 받으면 B는 0원, A는 4,000만원이며 B를 연속해서 4개 받는 방식이 아닙니다.

14. 이벤트와 쿠폰 운영하기

이벤트 자동 보상

누적 결제 이벤트에서 이름, 기준금액, 보상 종류, 지급량, 기간과 회원별 횟수 한도를 입력합니다. 포인트·캐시·특별 박스·버닝·확정 상품 중 선택하고 필요한 연결 박스나 상품을 지정합니다. 이벤트 등록 또는 이벤트 수정 저장 후 사용자 누적 혜택 화면에서 조건을 확인합니다.

충전 조건을 충족하면 보상을 지급합니다. 반복 지급은 기준금액의 2배·3배 등 다음 회차 목표를 채워야 합니다. 천장 게이지 초기화와 이벤트 누적액은 별개입니다. 지급 이력이 있는 조건은 변경이 제한되므로 새 이벤트로 등록합니다. 품절·기간·금액 오류를 확인하고, 미지급 보상은 사용자 혜택 화면에서 조건 충족 후 다시 받습니다.

가입과 출석 및 친구 추천

같은 메뉴의 가입 출석 친구 추천 혜택에서 지급 포인트와 추천 최소 충전액을 저장합니다. 가입은 최초 1회, 출석은 KST 하루 1회, 추천은 자기추천·중복을 제한합니다. 실제 다중 계정 판별에는 본인확인 연동이 필요합니다. 지급 기록과 추천 처리 내역으로 결과를 확인합니다.

쿠폰

새로 등록에서 이름·코드·혜택·사용 기간·총 사용 가능 횟수와 상태를 입력합니다. 한국 날짜 기준으로 기간과 잔여 횟수를 검사합니다. 횟수는 회원별이 아니라 해당 쿠폰의 전체 주문 기준입니다. 저장 후 사용자 구매 화면에서 적용 가능 여부와 할인액을 확인합니다. 자동 배포는 연결되지 않았습니다.

안내 게시물은 이벤트 메뉴 아래 목록에서 별도 관리합니다. 게시물을 등록했다고 자동 보상 조건까지 생기는 것은 아닙니다. 날짜가 거꾸로이거나 필수 이름·금액·횟수가 잘못되면 수정 후 저장하세요.

15. 공지와 홍보 및 공개 정보 관리하기

공지사항과 홈 배너

공지사항은 제목·본문·공개 상태를 저장한 뒤 사용자 공지 목록과 본문을 확인합니다. 홈 배너는 제목·이미지 업로드·연결 주소·기간을 등록하는 운영 기록입니다. 현재 홈의 고정 이미지와 자동 연결되지 않으므로 등록만으로 배너가 바뀌었다고 안내하지 않습니다.

당첨 공개 설정

사용자 홈에 당첨 피드 표시와 회원 이름 일부 가림을 선택하면 즉시 반영됩니다. 실제 개봉 기록만 사용하며 임의 당첨 등록은 지원하지 않습니다. 회원 본인이 공개를 끈 기록은 제외됩니다. 공개 피드와 개인 언박싱 내역을 구분해서 확인합니다.

약관·정책

사업자 공개 정보와 고객센터 안내를 준비하고 정책 종류·제목·본문·버전·시행일·상태를 입력합니다. 저장 후 사용자 약관·개인정보·포인트·취소·배송·천장 보상 정책 화면을 확인합니다. 미래 시행일은 아직 공개되지 않습니다. 새 거래에는 당시 정책이 보존되며 과거 거래의 정책을 덮어쓰지 않습니다.

게시물이 안 보이면 상태와 날짜부터 확인합니다. 사업자 확인, 실제 법률 검토, 회원 재동의 통지는 자동으로 수행되지 않습니다. 운영사가 작성한 정책은 검토 없이 기본 문구로 바꾸지 않습니다.

16. 문의 응대와 하루 마감 확인

1:1 문의

문의 내용을 펼쳐 회원과 접수 유형을 확인합니다. 수정에서 답변과 처리 상태를 저장한 뒤 사용자 내 문의에서 답변을 확인합니다. 계정 복구·탈퇴·개인정보 권리·취소반품 요청도 이 목록으로 들어옵니다. 답변 저장은 실제 탈퇴나 환불을 실행하는 버튼이 아닙니다.

자주 묻는 질문

반복 문의는 질문·답변·분류를 등록하고 공개 상태로 저장합니다. 사용자 고객센터에서 내용이 보이는지 확인합니다. 숨긴 항목이 계속 보이면 상태와 같은 질문의 중복 등록 여부를 살펴봅니다.

업무를 마칠 때

  1. 승인 대기 환급, 배송 요청, 답변 대기 문의를 확인합니다. 처리 후 관련 사용자 잔액이나 상태를 다시 봅니다.
  2. 판매 중 박스의 수량·상품 재고·확률 합계와 천장 보상 상품 재고를 점검합니다.
  3. 원장·지급 내역에서 예상하지 못한 변경을 확인합니다. 금액 정정에는 원래 거래와 사유를 남깁니다.
  4. 기한이 지난 보관 상품은 현재 기한 확인 및 처리로 점검합니다. 브라우저가 닫힌 동안에는 상시 예약 작업이 실행되지 않습니다.

현재 제작본은 실제 인증·DB·PG·택배·문자 발송이 연결되지 않았습니다. 실운영에는 개발자 문서에 기재한 서버 거래·권한·예약 처리와 운영 정책 확정이 필요합니다. 이 가이드의 화면 조작과 실제 외부 업무를 구분해서 인수해야 합니다.
