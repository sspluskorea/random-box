## 구현 내용

- 승인된 순충전액 기준 B 1,000만원·A 4,000만원 독립 천장 게이지, 카테고리별 확정보상 수령 시 해당 게이지 0 초기화(초과금액 이월 없음)
- 천장 보상 A~E등급별 활성·금액 설정, 상품 종류 추가·변경·비활성, 등급·종류별 지급 상품 직접 지정과 변경 전후 이력
- 필수 동의 확인 옵션과 제3자 제공 안내·동의 당시 기록, 품절 대체상품 제안 및 사용자 수락·거절
- 악성 주소·파일 형식 위조·CSV 수식·손상된 저장 데이터·오래된 탭 덮어쓰기·저장 실패 거래 방어
- A~E 상품 등록, 상품별 확률과 합계 검증, 변경 이력, 구매 당시 확률 보존
- 누적 금액 이벤트, 특별 박스·버닝 이용권, 가입·출석·추천 보상
- 기본 60% 캐시 전환, 당첨 당시 조건 보존, 신규 일반 상품의 240시간 자동 포인트 전환
- 충전 전체·부분 취소, 상품 환급, 회원별 포인트·캐시, 배송·문의·공지·약관 등 관리자 24개 메뉴
- 관리자 목록은 필수 정보만 표시하고 상세는 아래로 펼침. 상품별 당첨내역·판매내역 버튼으로 상품 ID 필터 조회
- 업로드 이미지, 상품 상세, 개봉 애니메이션, 마이페이지 및 모바일 화면

## 실행과 검증

Node.js 22.12 이상을 사용합니다.

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173
npm run build:pages
npm test
npm run test:harness
```

`src/demoStore.js`와 `src/platformModel.js`가 거래·보상 상태를 관리합니다. `tests/`에는 회귀 테스트와 독립 QA 경계 테스트가 있습니다. `build:pages`는 `docs/`에 게시 파일을 만들며 GitHub Pages는 `main`의 `/docs`를 사용합니다. `public/guides/`는 HTML·Word 안내서이며 `scripts/build-guides.py`에서 생성합니다(Python과 python-docx 필요).

## 실제 연동 범위

회원가입·로그인·결제는 빈 입력으로도 흐름을 확인할 수 있습니다. 실제 DB, 인증, PG, 배송·문자 발송은 연결하지 않았으며 관리자 페이지도 공개된 제작본입니다. 실제 개인정보와 카드정보를 입력하지 않습니다. 필수 동의 확인은 기본적으로 꺼져 있으며 관리자 약관·정책에서 켤 수 있습니다. 브라우저 입력 검증과 충돌 감지는 실제 서버 권한·거래 원장·다중 요청 처리를 대신하지 않습니다.

데이터와 이미지는 브라우저 localStorage에 저장합니다. 동일 브라우저·동일 출처 탭끼리 변경을 공유하며 다른 기기와 공유하지 않습니다. 자동 전환은 페이지 실행·포커스 복귀·주기 점검 시 처리되고 닫힌 브라우저에서 예약 실행하지 않습니다. 캐시는 사이트 내 구매용으로 계좌 출금하지 않습니다.

최신 검증은 회귀 테스트 169개와 사용자·관리자 연동 하네스 24개를 통과했습니다.

기존 6개 박스의 금액대 방식과 새 리워드 박스의 상품별 확률 방식을 지원합니다. 평균 당첨 간격은 보장 횟수가 아닙니다. 서버 추첨·권한·동시성·결제·법률 검토는 실제 운영 전 별도 구축 대상입니다. 상세 범위와 운영 확정 사항은 개발자 전달 문서를 확인해 주세요.

기존 `docs/` 조사·기획 문서는 참고 이력입니다. 현재 기능은 최신 가이드와 코드·테스트를 기준으로 확인합니다.

의존성 보안 점검에서 확인한 항목은 Vite 7.3.7과 source-map-js 1.2.2로 패치했습니다. 현재 잠금 파일 기준 pnpm audit 결과 알려진 취약점 0건입니다. 이는 실제 서버·운영 보안 검증 완료를 의미하지 않습니다.
