# 모두의 박스

React·Vite 랜덤박스 사용자 화면과 관리자 콘솔입니다.

- 사용자: https://sspluskorea.github.io/random-box/#home
- 관리자: https://sspluskorea.github.io/random-box/#admin
- 소스: https://github.com/sspluskorea/random-box

## 주요 기능

포인트 충전·취소 → 박스 구매 → 개봉 애니메이션 → 당첨 상품 보관 → 배송 신청 또는 포인트 전환·환급을 제공합니다. 회원가입·로그인은 빈 입력으로도 확인할 수 있습니다.

관리자는 핵심 23개 메뉴에서 박스·상품·확률, 충전·환급 정책, 회원별 포인트, 주문·배송, 공지·이벤트·문의·약관을 관리합니다. 목록에 상세 정보를 바로 표시하며 이미지 업로드와 상품별 당첨 확률·이미지 표시를 지원합니다.

## 실서비스 전환 검증

[실서비스 전환 검증 및 개발 요건](docs/실서비스-전환-검증.md)에 페이지별 보완, 정책 검토, 운영 전 필수 연동과 검증 기준을 정리했습니다. 개인정보·포인트·취소·반품·배송·당첨 공개 정책 6종, 사업자 정보, 계정 복구·탈퇴·권리 요청, 취소·반품 접수와 거래 명세 화면을 제공합니다. 요청은 기존 관리자 1:1 문의에 연결되며 자동 환불·삭제·인증은 실행하지 않습니다. 구매·충전에 당시 정책 버전과 본문을 보존합니다.

## 로컬 실행과 검증

Node.js 22 이상이 필요합니다.

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173
```

별도 터미널에서 빌드 후 검증합니다.

```sh
npm run build:pages
npm test
npm run test:harness
```

`src/`에 화면 코드, `tests/`에 테스트, `public/assets/`에 기본 이미지가 있습니다. `src/demoStore.js`는 거래와 상태 변경을 담당합니다. `build:pages`는 `docs/`에 배포 파일을 생성합니다. GitHub Pages는 `main`의 `/docs`를 게시합니다.

## 연결 범위

실제 결제·회원 인증·배송 접수·외부 DB가 연결되지 않은 시연용입니다. 관리자 화면도 공개되는 프로토타입이며 실제 관리자 인증을 제공하지 않습니다. 개인정보나 실제 결제 정보를 입력하지 마세요.

변경 내역과 이미지는 해당 브라우저의 localStorage에 저장됩니다. 같은 브라우저·동일 출처의 사용자/관리자 탭끼리 동기화되지만, 다른 개발자나 다른 기기와는 공유되지 않습니다. 이미지를 자동 축소하며 저장 공간 부족 시 오류를 안내합니다.

추첨은 금액대 선택 후 해당 구간의 재고 상품 중 균등 선택하는 모의 방식입니다. 평균 당첨 간격은 당첨을 보장하는 횟수가 아닙니다. 실제 서비스 전 서버 추첨·인증·결제·이미지 저장소·권한·감사 및 법률 검토가 필요합니다.

기존 `docs/`의 조사·기획 문서는 참고자료입니다. 현재 구현 범위는 이 README와 코드·테스트를 기준으로 확인합니다.
