# 모두의박스

페이 충전 → 랜덤박스 구매·개봉 → 상품 배송 또는 포인트 전환 흐름을 확인하는 React·Vite 프로토타입입니다.

- [사용자 화면](https://sspluskorea.github.io/random-box/#home)
- [관리자 화면](https://sspluskorea.github.io/random-box/#admin)
- [서비스 이용 가이드](https://sspluskorea.github.io/random-box/guides/service-guide.html)
- [개발자 전달 문서](https://sspluskorea.github.io/random-box/guides/developer-guide.html)

관리자 상단에서 안내서를 열 수 있으며 Word 파일도 내려받을 수 있습니다.

## 구현 내용

- 충전한 페이와 상품 전환·참여 보상으로 받은 포인트를 별도 관리합니다. 구매 시 포인트부터 사용하고 부족한 금액은 페이로 결제합니다.
- 페이는 환전 신청할 수 있으며 신청 시 예약 차감합니다. 승인은 추가 차감하지 않고 거절·취소는 한 번 복원합니다. 포인트는 환전할 수 없습니다.
- 상품 포인트 전환은 기본 60%이며 기본 반환율과 상품별 반환율을 관리자에서 설정합니다. 지급액은 기준가격 × 당첨 당시 반환율의 정수 내림값입니다. 기존 확정 반환액은 보존합니다.
- 개봉 횟수와 당첨 상품 등급에 따른 독립 천장 게이지를 제공합니다. A~E별 적용 여부, 적립 시작 개봉 횟수, 해당 등급 당첨 1회 적립량, 확률 상승 %p, 적용 횟수를 설정합니다.
- 게이지 100%는 다음 개봉부터 해당 등급의 확률을 높입니다. 동시에 준비되면 A→E 순서로 한 등급만 적용하고 나머지 등급 확률은 비례 조정합니다. 상품 당첨을 보장하지 않습니다.
- 이전 누적 결제금액 기준 확정보상은 신규 지급을 종료하고 기존 기록을 보존합니다. 새 개봉 게이지는 과거 개봉에 소급하지 않습니다.
- A~E 상품 등록, 상품별 확률과 합계 100% 검증, 재고·판매 상태, 확률 변경 이력, 개봉별 적용 확률 기록을 관리합니다.
- 누적 금액 이벤트, 특별 박스·버닝 이용권, 가입·출석·추천 보상은 개봉 게이지와 별도 운영합니다.
- 당첨 후 기본 240시간 미수령 시 포인트 자동 전환, 충전 취소, 배송·문의·공지·약관 등을 관리자 24개 메뉴에서 관리합니다.
- 관리자 목록은 필수 정보만 표시하고 상세는 아래로 펼칩니다. 상품별 당첨·판매내역 버튼은 해당 상품으로 필터링합니다.
- 필수 동의 확인 옵션, 동의 당시 기록, 대체상품 수락·거절, 업로드 이미지, 상품 상세, 마이페이지와 모바일 화면을 제공합니다.
- 악성 주소·파일 형식 위조·CSV 수식·손상된 저장 데이터·오래된 탭 덮어쓰기·저장 실패 거래를 방어합니다.

## 실행과 검증

Node.js 22.12 이상을 사용합니다.

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173
npm run build:pages
npm test
npm run test:harness
```

거래와 보상 상태는 `src/demoStore.js`, `src/platformModel.js`, `src/financialModel.js`, `src/openingGaugeModel.js`에서 관리합니다. `tests/`에는 회귀 및 독립 QA 테스트가 있습니다. `build:pages`는 `docs/`에 게시 파일을 만들며 GitHub Pages는 `main`의 `/docs`를 사용합니다. `public/guides/`의 HTML·Word 안내서는 `scripts/build-guides.py`에서 생성합니다(Python과 python-docx 필요).

최신 검증은 회귀 테스트 191개와 사용자·관리자 연동 하네스 32개를 통과했습니다. 브라우저에서도 페이 환전 신청·취소 후 잔액 복원과 새 게이지 화면을 확인했습니다.

## 실제 연동 범위

회원가입·로그인·결제는 빈 입력으로도 흐름을 확인할 수 있습니다. 실제 DB, 인증, PG, 계좌 송금, 배송·문자 발송은 연결하지 않았으며 관리자도 공개된 제작본입니다. 실제 개인정보와 카드정보를 입력하지 않습니다. 필수 동의 확인은 기본적으로 꺼져 있으며 관리자 약관·정책에서 켤 수 있습니다. 브라우저 입력 검증과 충돌 감지는 서버 권한·거래 원장·동시 요청 처리를 대신하지 않습니다.

데이터와 이미지는 브라우저 localStorage에 저장합니다. 동일 브라우저·동일 출처 탭끼리 변경을 공유하며 다른 기기와 공유하지 않습니다. 자동 전환은 페이지 실행·포커스 복귀·주기 점검 시 처리되며 닫힌 브라우저에서 예약 실행하지 않습니다. 페이 환전은 상태와 잔액 처리까지 구현했으며 실제 송금은 하지 않습니다.

기존 금액대 방식과 상품별 확률 방식을 모두 지원합니다. 평균 당첨 간격은 보장 횟수가 아닙니다. 서버 추첨·권한·동시성·결제·환전 및 법률 검토는 실제 운영 전 별도 구축 대상입니다. 상세 범위와 운영 확정 사항은 개발자 전달 문서를 확인해 주세요.

기존 `docs/` 조사·기획 문서는 참고 이력입니다. 현재 기능은 최신 가이드와 코드·테스트를 기준으로 확인합니다.

의존성 보안 점검 항목은 Vite 7.3.7과 source-map-js 1.2.2로 패치했습니다. 잠금 파일 기준 알려진 취약점 0건을 확인했습니다. 이는 실제 서버·운영 보안 검증 완료를 의미하지 않습니다.
