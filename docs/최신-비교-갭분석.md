# 랜덤박스 서비스 비교와 운영 기능 점검

화면 수보다 거래가 끝까지 연결되는지가 중요합니다. 현재 미팅용 페이지는 가입·충전·개봉·환불·배송과 관리자 기본 메뉴를 갖추고 있습니다. 이번 비교에서 우선 보강할 부분은 상품 단위 확률, 품절 처리, 전환 취소, 보관기한, 정책 변경 이력과 운영 대사입니다. 아래 구현 상태는 이번 확장 작업 전 코드와 기존 기능표를 기준으로 분류했습니다. 최종 구현 여부와 검증 결과는 별도 검수 기록을 따릅니다.

## 해시박스는 한국과 미국을 구분해야 합니다

한국 홈은 주식회사 티렉스와 원화 박스를, 미국 홈은 Mysteryhub Technologies LLC와 달러 박스를 표시합니다. 미국 화면에는 Stripe, 지역·언어 선택, 별도 배송·반품 정책 메뉴가 노출됩니다. 미국의 동의문이나 가격을 한국 서비스 정책으로 인용하지 않습니다. [한국 홈](https://hashbox.monster/) · [미국 홈](https://us.hashbox.monster/)

한국 확률고지 검색 응답에서는 등급 설정확률·누적 집계·차이와 등급 내 상품의 조건부 확률을 확인했습니다. 직접 페이지 요청은 일부 실패했으므로 해당 표의 현재 상품 전체를 확정 수치로 옮기지 않았습니다. 상품의 최종확률은 등급 확률과 등급 내부 확률을 곱해야 하며, 내부 확률만 크게 보여주면 오해할 수 있습니다. [한국 확률고지](https://hashbox.monster/probability?page=1)

한국 FAQ는 언박싱 기록의 시각·상품·등급·난수·테스트 여부 등을 설명합니다. 기록을 남긴다는 사실만으로 추첨 이전의 공정성이나 배송 이행까지 증명되는 것은 아닙니다. 제작물도 브라우저 시연 기록을 블록체인 검증·제3자 인증이라고 표현하면 안 됩니다. [한국 FAQ](https://hashbox.monster/cscenter/qna)

## 확인된 설계 방향

최신 트렌드는 시장점유율이나 증가율로 검증하지 못했습니다. 여기서는 위 공개 페이지에서 관찰된 설계 방향만 정리합니다.

1. 결과 확인 후 배송·포인트 전환 등 후속 선택을 제공하는 구조가 반복됩니다. 선택 후 취소 가능 시점과 잔액 회수가 함께 필요합니다.
2. 무료박스·구독·추천·랭킹 등 반복 방문 기능이 존재합니다. 보상 조건과 중복 지급 방지가 동작해야 합니다. [해시박스 한국 홈](https://hashbox.monster/) · [랭킹 안내](https://www.hashbox.monster/story/ranking/home/daily)
3. 단순 당첨 홍보에서 확률표·결과 기록·집계 비교로 신뢰 정보를 확장한 사례가 확인됩니다. 모든 경쟁사가 같은 수준이라고 판단하지 않습니다.
4. 해외 서비스는 통화뿐 아니라 결제·연령 동의·배송·반품 정책을 분리합니다. 국내 미팅용 페이지에 해외 정책을 그대로 적용할 필요는 없습니다.
