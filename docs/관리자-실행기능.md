# 관리자 실행 기능 및 미팅 시연표

관리자 화면은 47개 메뉴로 구성됩니다. 아래 124개 항목은 화면에서 실행할 수 있는 작업 단위입니다. 같은 버튼을 단순히 여러 메뉴에 반복 집계하기보다 실제로 입력하거나 확인하는 운영 정보를 기준으로 정리했습니다.

회원·개봉·충전·환불·주문·원장은 사용자 화면에서 발생한 체험 데이터를 공유합니다. 상품·박스·설정·콘텐츠 편집은 저장 후 다시 확인할 수 있습니다. 공급사·정산·택배사·반품·권한 등 보조 메뉴는 등록·수정 가능한 운영 기록입니다. 실제 송금, 택배사 전송, 권한 강제, 예약 알림 실행, PG 취소, 본인인증을 수행하는 운영 시스템은 아닙니다.

## 연결 범위와 시연 순서

1. 사용자 화면에서 빈 입력 상태로 가입·로그인을 완료하고 충전합니다.
2. 관리자 충전 내역과 회원별 포인트에서 해당 데이터가 반영되는지 확인합니다.
3. 금액대별 확률에서 박스 설정을 변경하고 사용자 상세 화면 확률 안내를 확인합니다.
4. 사용자 화면에서 박스를 개봉하고 관리자 개봉 이력·보관함을 확인합니다.
5. 미수령 환불을 신청한 후 관리자에서 승인 또는 반려하고 사용자 잔액을 확인합니다.
6. 배송 신청 후 관리자에서 주소·택배사·송장·배송 상태를 변경합니다.
7. 공지·이벤트·약관을 편집한 후 사용자 화면에서 변경 내용을 확인합니다.

확률 계산은 독립 추첨 가정입니다. 평균 횟수와 50%·90% 도달 횟수는 당첨 보장을 의미하지 않습니다. 외부 서비스의 실제 당첨 확률과 이번 체험용 서비스에 입력한 확률은 별도입니다.
