# 랜덤박스 서비스 비교 및 운영정책 검토

이번 제작은 클라이언트 미팅에서 가입부터 상품 수령·반환까지 직접 눌러볼 수 있는 시연 환경입니다. 실제 인증, 결제, 송금, 배송, 데이터베이스 연결은 사용하지 않습니다. 경쟁사 정책은 기능 설계 참고자료이며, 아래에 기록한 조건을 그대로 본 서비스의 확정 정책으로 적용하지 않습니다.

### 가자박스

공식 FAQ의 전환 기준은 5,000~19,900원 상품의 경우 5,000원 박스에서 3,000P, 10,000원 박스에서 6,000P 지급입니다. 20,000~29,900원 상품은 정가의 60%, 30,000~1,999,000원 상품은 80%이며, 2,000,000원 이상은 포인트 전환 불가로 안내합니다. 상품 복구는 24시간 기준 5회이며 지급 포인트를 회수합니다. 묶음배송은 합계 100게이지 내에서 지원하고 예외 상품이 있으며, 배송비는 건별 3,000원입니다. 이는 현금 환불률이 아니라 사이트 내 포인트 지급 기준입니다. [가자박스 공식 FAQ](https://www.gazabox.com/Board/Board?b_type=2)

### 오픈박스

공개 상품 상세에서 랜덤박스 가격 10,000원, 별도 포인트 구매 가격, 배송 게이지를 함께 확인했습니다. 재확인한 Loop 콰이어트 2 이어플러그는 35,900P 및 배송게이지 40으로 표시합니다. 이전 기록의 게이지 50은 최신 확인값 40으로 정정합니다. 가격과 게이지가 분리되어 있으므로 관리자 상품 등록에도 서로 다른 필드가 필요합니다. ### 초콜릿박스·심쿵박스

초콜릿박스는 공식 앱 소개에서 결제 후 리워드 결과를 확인하고 상품 교환 또는 포인트 전환을 선택하는 서비스로 설명합니다. 비슷한 이름의 수입 소품 쇼핑몰 정책은 본 비교에서 제외했습니다. [초콜릿박스 공식 앱](https://play.google.com/store/apps/details?hl=ko&id=io.chocolatebox.app) · [운영 웹사이트](https://chocolatebox.io/)

심쿵박스는 공식 앱의 개발자 정보와 연결 웹사이트까지 확인했습니다. 웹사이트 본문은 추출되지 않았으므로 충전수수료나 환불률을 단정하지 않습니다. [심쿵박스 공식 앱](https://play.google.com/store/apps/details?hl=ko&id=com.mdsoft.heartbox) · [공식 웹사이트](https://heartbox.co.kr/)

### 더블업

공식 약관은 일부 상품의 미수령 포인트 전환을 상품가의 60~80%로 설명하며, 전환 포인트는 현금 환불이나 외부 사용이 불가하다고 명시합니다. 개봉 전 7일 이내 취소와 개봉 후 청약철회 제한을 구분합니다. 다만 제9조는 상품 보관 90일과 60~80% 자동전환, 제22조는 30일과 박스 구입금액 60% 전환을 설명합니다. 기간과 산정 기준이 충돌하므로 하나의 확정 정책으로 인용할 수 없습니다. 이번 제작에서는 보관기간·기준금액·전환율을 한 설정에서 관리하는 구조가 필요합니다. ### 해시박스 몬스터

공식 약관은 미개봉 박스의 원결제수단 환불과 포인트 결제분의 포인트 반환을 구분합니다. 개봉한 경우 인벤토리 상품 회수 후 50% 금액 환불을 안내하고, 이미 포인트로 전환해 상품이 소멸한 경우는 환불 불가로 설명합니다. 약관에 적힌 사업자 정책의 확인 결과이며, 해당 조항의 법적 유효성을 검증한 것은 아닙니다. 개봉 애니메이션의 상품 노출 빈도와 실제 당첨확률이 무관하다는 안내도 존재합니다. [해시박스 회원가입 페이지 내 이용약관](https://hashbox.monster/mypage/signup)

공개 홈에는 9,900원부터 99,900원까지 여러 가격대의 박스, 무료 박스, 구독, 랭킹, 인벤토리, 포인트 교환소, 언박싱 기록이 노출됩니다. 사이트가 밝힌 회원수나 구매량을 독립적으로 검증하지는 않았습니다. [해시박스 공식 홈](https://hashbox.monster/)

## 이번 시연 설계에 적용할 정책 구조

| 구분 | 사용자 확인 내용 | 관리자 관리 내용 |
|---|---|---|
| 충전 | 결제 금액, 유료 충전 포인트, 무상 보너스, 결제수단 | 충전 상품·보너스·한도·노출·충전내역 |
| 박스 결제 | 수량, 쿠폰, 포인트 사용액, 최종 결제액 | 가격, 구매 제한, 판매 상태, 주문 상태 |
| 개봉 | 개별 상품 확률, 결과, 보관함 추가 | 박스·가격 구간별 확률, 합계 검사, 결과 로그 |
| 상품 포인트 전환 | 상품 기준가, 전환율, 받을 포인트 | 금액 구간별 전환율, 전환 가능 여부, 복구 |
| 개봉상품 반환 | 반환 기준금액, 공제율, 공제액, 지급 방식, 상품 회수 | 반환 승인·반려·완료, 수수료 정책, 중복처리 방지 |
| 미사용 충전금 환불 | 환불 가능 유료 잔액, 보너스 제외, 반환액 | 유료·무상 잔액 분리, 환불 내역, 처리상태 |
| 배송 | 주소, 묶음 상품, 배송비, 상태 | 배송 요청, 합포장, 택배사, 송장, 반송 |

미수령상품을 포인트로 전환하는 것과 결제금액을 환불하는 것은 다른 기능입니다. 시연에서는 두 메뉴를 분리하고, 수수료는 관리자에서 설정한 데모 정책임을 표시합니다. 외부 서비스의 관리자 화면은 공개되어 있지 않으므로 상품·재고·환불·회원 관리 구조는 공개 사용자 흐름을 운영하기 위해 필요한 자체 설계입니다.
