1. 서비스 이용 순서

모두의박스는 포인트를 충전하고 랜덤박스를 구매한 뒤, 당첨 상품을 배송받거나 캐시로 전환하는 서비스입니다. 충전 실적에 따른 천장 보상과 누적 혜택은 마이페이지에서 함께 확인합니다.

처음 이용할 때

  1. 회원가입에서 회원정보와 동의 항목을 확인합니다. 로그인 후 마이페이지에서 포인트와 보관 상품을 확인합니다.
  2. 포인트 충전에서 금액과 보너스를 확인하고 승인을 진행합니다. 충전금과 보너스는 따로 표시됩니다.
  3. 랜덤박스에서 구성 상품과 확률을 확인합니다. 박스 열기를 누르면 수량과 결제수단을 선택할 수 있습니다. 연락처를 다시 입력할 필요는 없습니다.
  4. 구매가 완료되면 박스가 열리고 결과가 표시됩니다. 애니메이션을 건너뛰어도 이미 결정된 결과와 결제금액은 바뀌지 않습니다.
  5. 보관함에서 상품을 선택해 배송을 신청하거나, 표시된 금액을 확인하고 캐시로 전환합니다.

화면을 확인하는 방법

사용자와 관리자 화면을 같은 브라우저에서 열면 설정과 거래 기록이 서로 반영됩니다. 가입·로그인·결제 입력란은 비워 두고도 흐름을 확인할 수 있습니다. 실제 본인인증, 카드 승인, 배송 접수는 연결되지 않았으므로 실제 개인정보나 카드정보는 입력하지 않습니다.

다른 기기나 브라우저에는 별도의 기록이 보입니다. 현재 화면은 서비스 흐름을 검토하는 제작본이며, 공개된 관리자 주소에도 실제 운영 권한 인증이 적용되어 있지 않습니다.

2. 나의 쇼핑과 이용 기록

메뉴사용 방법과 확인할 내용
랜덤박스와 검색박스 이름·카테고리로 찾습니다. 박스 열기는 구매 화면, 담기는 장바구니, 하트는 관심 박스로 연결됩니다.
구성과 확률상품 이미지·등급·재고·최종 확률을 확인합니다. 상품명을 누르면 브랜드, 사양, 구성, 기준가격, 설명과 상세 이미지가 나옵니다.
장바구니와 관심 박스담은 박스를 확인하고 구매할 박스를 선택합니다. 구매 화면에서 수량·잔액·최종 결제금액을 다시 확인합니다.
마이페이지포인트·캐시·보관 상품·배송 진행과 천장 보상을 한 번에 확인합니다. 세부 내역은 왼쪽 메뉴로 이동합니다.
보관함배송을 기다리는 상품과 기한을 확인합니다. 배송 신청, 캐시 전환, 미수령 환급 중 가능한 처리를 선택합니다.
주문·배송신청 상품, 주소, 배송비와 상태를 확인합니다. 관리자가 등록한 택배사와 송장번호가 표시됩니다.
나의 언박싱본인의 박스 구매와 당첨 기록을 확인합니다. 공개 언박싱과 구분되어 있습니다.
언박싱과 당첨 랭킹공개 선택이 켜진 개봉 기록을 확인합니다. 현재 브라우저 기록과 예시 표시는 실제 전체 회원의 검증 자료를 뜻하지 않습니다.
거래 명세본인의 충전·구매 등 거래 내용을 확인합니다. 실제 세금계산서나 PG 영수증 발급 기능과는 별도입니다.
이용방법과 확률 안내충전부터 수령까지의 순서, 추첨 방식과 확률 해석을 확인합니다.

평균 당첨 간격은 장기간 반복했을 때의 평균입니다. 1%는 평균 100회당 1회라는 뜻이며, 100회 안에 반드시 당첨된다는 뜻은 아닙니다. 100회 중 한 번 이상 당첨될 확률은 약 63.4%입니다.

3. 포인트와 캐시 및 취소

잔액은 세 가지로 구분합니다

잔액용도
충전 포인트승인된 충전 원금입니다. 천장과 누적 이벤트의 인정 결제금액에 포함됩니다.
보너스 포인트충전 보너스·출석·이벤트·자동 전환으로 받습니다. 천장 인정금액에는 포함되지 않습니다.
캐시상품 전환이나 이벤트로 받는 사이트 내 구매용 잔액입니다. 계좌 출금 기능은 없습니다.

충전 내역과 취소

포인트 내역에서 충전금, 보너스, 사용 기록을 확인합니다. 미사용 충전은 취소 버튼으로 남은 원금과 회수 보너스를 확인한 뒤 처리합니다. 관리자는 금액을 입력해 부분 취소할 수도 있습니다. 원금이나 회수할 보너스가 부족하면 즉시 취소되지 않으며 고객센터 검토가 필요합니다.

상품을 배송받지 않을 때

캐시 전환은 상품 기준가격의 기본 60%를 받는 방식입니다. 상품별 고정 전환액이 있으면 그 금액이 우선합니다. 당첨 당시의 조건을 보존하므로 이후 관리자가 전환율을 바꿔도 이미 받은 상품의 금액은 달라지지 않습니다.

상품 미수령 환급은 구매금액을 기준으로 수수료를 계산하는 별도 절차입니다. 상품 가치가 높아도 환급 기준이 커지지 않습니다. 캐시로 구매한 상품은 캐시로, 포인트 구매분은 사용한 잔액 종류에 맞춰 반환합니다. 관리자 승인 방식이면 승인 전에는 잔액이 늘어나지 않습니다.

새 일반 당첨 상품은 기본 10일 이내 수령을 신청해야 합니다. 기한이 지나면 당시 전환액을 보너스 포인트로 지급합니다. 3일 전과 1일 전 구간에 화면을 열면 알림함에 안내합니다. 문자·이메일은 발송하지 않습니다. 천장 확정보상과 배송 신청 상품은 제외하며, 기한이 없던 과거 상품에는 소급 적용하지 않습니다.

취소·반품 신청은 상품 하자나 배송 문제 등을 접수하는 창구입니다. 상품 미수령 환급 수수료가 모든 반품에 일괄 적용되는 것은 아닙니다. 접수 후 고객센터 답변을 확인합니다.

4. 천장 보상과 참여 혜택

A와 B는 각각 쌓입니다

기본 기준은 B등급 1,000만원, A등급 4,000만원입니다. 승인된 충전 원금에서 취소한 금액을 차감합니다. 같은 포인트로 박스를 구매하거나 캐시를 다시 사용해도 적립금액은 늘지 않습니다. 일반 추첨으로 A~E 상품을 받아도 게이지는 초기화되지 않습니다.

천장 화면에서 남성 명품·여성 명품·가전제품 중 카테고리를 선택하고 지급 예정 상품을 확인합니다. 수령하면 상품이 보관함에 들어오고 해당 등급의 기준금액만 차감됩니다. 재고가 없으면 지급하지 않고 받을 권리를 유지합니다.

예시처리 결과
4,000만원 충전A 4,000만원, B 4,000만원으로 각각 계산합니다.
B 보상 1회 수령B는 3,000만원이 남고 A는 4,000만원을 유지합니다.
이후 A 보상 수령A는 0원, B는 3,000만원입니다.
보상 후 100만원 충전 취소A에 정산 필요액 100만원이 생기며 B는 2,900만원입니다. 받은 상품을 자동 회수하지는 않습니다.

누적 결제 혜택

기본 구간은 100만·200만·300만·500만·1,000만원입니다. 충전 조건을 충족하면 설정된 포인트, 캐시, 특별 박스 이용권, 버닝 이용권 또는 상품을 지급합니다. 반복 이벤트는 다음 회차에 추가 기준금액을 채워야 합니다. 재고 등으로 지급되지 못한 혜택은 조건을 확인한 뒤 다시 받을 수 있습니다.

버닝은 지정 박스의 A등급 합산 확률을 기본 10%로 조정하는 이용권입니다. 나머지 등급은 비율에 맞게 조정됩니다. 구매 전에 최종 확률과 남은 사용 횟수를 확인합니다.

가입 축하 보상은 최초 1회, 출석은 한국 시간 기준 하루 1회 지급합니다. 친구 초대는 추천 코드를 등록하고 신규 회원의 유효 충전 조건을 충족하면 양쪽에 지급합니다. 기본 보상은 가입 1,000P, 출석 100P, 추천 양쪽 각 1,000P이며 최소 충전 조건은 1만원입니다.

5. 관리자에서 상품과 거래 처리하기

관리자 상단의 서비스 이용 가이드와 개발자 전달 문서 버튼으로 이 안내서를 다시 열 수 있습니다. 메뉴 검색으로 필요한 화면을 찾고, 목록에서 상세 기록을 바로 확인합니다. 제공되는 CSV 내보내기는 현재 목록을 확인할 때 사용합니다.

관리자 메뉴처리 순서와 반영 결과
랜덤박스 관리새로 등록 또는 수정 → 이름·가격·수량·판매 상태 설정 → 이미지 업로드 → 구성과 확률 확인 → 저장합니다. 대표·상세 이미지는 수정창에서 관리합니다.
상품별 당첨 확률박스별 상품과 확률을 입력합니다. 합계 100%, 평균 간격, 누적 가능성, 등급 합계와 예상 원가를 확인합니다. 변경 전후 기록을 남깁니다.
상품 등록·재고A~E 등급, 브랜드·사양·가격·재고·판매 상태를 입력합니다. 대표·상세 이미지를 업로드하면 사용자 상품 화면에 표시됩니다.
개봉·당첨 이력회원·박스·상품·구매금액과 당시 확률을 확인합니다. 현재 확률을 바꿔도 과거 거래 조건은 보존됩니다.
충전 내역충전 원금·보너스·취소금액을 확인합니다. 취소 금액을 입력하면 원금과 비례 보너스를 회수하고 천장 인정액을 정산합니다.
충전 금액·보너스선택 충전금액과 보너스율을 저장합니다. 사용자의 다음 충전 화면에 반영됩니다.
상품 미수령 환불요청별 구매가·수수료·반환액을 확인합니다. 승인 또는 반려 후 상품 상태와 원장을 확인합니다.
환불·수수료 정책환급 수수료와 승인 방식을 설정합니다. 기존 거래와 법정 반품 절차를 구분합니다.
상품 전환·복원 정책기본 캐시율과 자동 전환 시간을 설정합니다. 전환 기록과 취소 후 정산 검토를 확인합니다. 현재 기한 확인 버튼은 실행 시점의 만료를 처리합니다.
포인트 원장충전·사용·지급·회수 내역의 회원과 잔액 종류, 금액, 사유를 확인합니다. 캐시도 종류를 구분해 기록합니다.

6. 관리자에서 회원과 보상 운영하기

배송 신청과 회원 잔액을 확인하고, 천장 조건을 충족한 보상을 처리합니다. 금액을 정정할 때는 원래 거래와 정정 사유를 함께 확인합니다.

관리자 메뉴처리 순서와 반영 결과
주문·배송 관리신청 상품·주소·배송비 확인 → 상태·택배사·송장 등록 → 저장합니다. 사용자 주문 화면에 반영됩니다.
배송비·배송 정책기본 배송비와 무료배송 조건 등 수령 비용을 설정합니다. 사용자는 신청 전 적용 금액을 확인합니다.
회원 보관함회원별 당첨 상품, 수령 상태, 구매 조건과 전환 기한을 확인합니다. 중복 환급·배송 여부를 조회할 때 사용합니다.
회원 관리회원정보와 상태를 확인·수정합니다. 결제 인정금액, 천장과 보상 기록은 천장·보상에서 함께 확인합니다.
회원별 포인트·캐시회원과 잔액 종류를 확인하고 지급·차감 사유를 입력합니다. 저장 후 해당 회원 잔액과 원장 반영을 확인합니다.
천장·보상A·B 기준과 카테고리별 보상 재고를 확인합니다. 회원별 진행금액·수령 횟수·정산 필요액, 지급·초기화 이력을 조회합니다. 수동 정정·지급에는 사유를 남깁니다.

정산 기록 확인

충전 취소 후 정산 필요액이 생기면 관련 회원과 보상 지급 내역을 확인합니다. 검토 완료는 메모 기록이며 지급 상품 회수나 금액 정정은 별도의 처리입니다.

7. 콘텐츠와 고객지원 운영

회원에게 공개할 안내와 문의 답변을 관리합니다. 게시 상태와 시행일을 확인한 뒤 저장하고 사용자 화면에서 내용을 확인합니다.

관리자 메뉴처리 순서와 반영 결과

8. 운영 중 자주 확인할 내용

상품과 보상 설정 순서

  1. 상품 등록·재고에서 이미지와 상품정보를 먼저 저장합니다. 천장 전용 상품은 등급과 남성·여성·가전 카테고리를 함께 지정합니다.
  2. 랜덤박스에 상품을 연결하고 확률 합계를 100%로 맞춥니다. 사용 중인 구성 상품은 먼저 박스에서 제외한 뒤 삭제합니다.
  3. 사용자 화면에서 이미지·가격·확률을 확인합니다. 기본 6개 박스의 기존 금액대 방식은 유지되며 개별 상품 확률로 전환할 수 있습니다. 신규 리워드 시그니처 박스는 상품별 확률을 사용합니다.
  4. 천장 기준을 변경해도 진행 중인 회차는 기존 기준을 유지합니다. 보상 수령 후 시작하는 다음 회차부터 새 기준을 적용합니다.

문제가 생겼을 때

품절 보상은 재고를 보충하고 다시 지급합니다. 임의 대체 상품에 대한 동의 절차는 별도 개발 대상이므로 다른 상품을 임의로 배송하지 않습니다. 취소 후 정산 검토의 완료 버튼은 검토 메모를 저장하는 기능입니다. 캐시 회수나 천장 부족액 해소가 자동으로 처리되지는 않습니다.

커뮤니티는 글 등록과 열람, 선물함은 등록된 선물 기록을 확인하는 화면입니다. 공개 안내 이벤트의 참여 버튼은 참여 기록을 남깁니다. 이 기능만으로 실물 발송이나 모든 이벤트 보상이 자동 지급되지는 않습니다. 포인트샵과 상품 교환 게시판은 선택 기능으로 기본 주요 메뉴에서 제외했습니다. 해시패스는 제공하지 않습니다.

회원정보 수정에서 공개 선택과 기본 정보를 관리합니다. 알림함에서는 보상·수령 마감 안내를 확인합니다. 개인정보 권리 요청, 탈퇴와 계정 복구는 고객센터 접수로 연결되며 자동 인증·파기·비밀번호 변경을 실행하지 않습니다.
